# open-taranis

**Framework Python** créé pour coder des agents d’IA **(LLM) précis** et **rapidement**, avec support multi-provider.

Une philosophie centrée sur une approche **logic-coding only**.

---

Pour commencer, installez-le avec :

```bash
pip install open-taranis --upgrade
```

Et pour continuer, allez à la page suivante !
